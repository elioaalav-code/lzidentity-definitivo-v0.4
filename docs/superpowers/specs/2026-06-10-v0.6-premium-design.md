# v0.6 "Premium" — Chat redesign · Empty-state kit · Glass 27

Approved by Elio 2026-06-10 ("Vai così"). Scope picked from the v0.5 visual audit:
Chat redesign (landing phone mockup = the spec) + empty-states/sigil system + a
premium layer inspired by iOS 27 (WWDC 2026: Liquid Glass refined — user-controlled

## Hard constraints (carried from every prior overhaul)
- HONESTY: no fake data. No MESH/LZ transport badges on real messages (DM chat is
  Nostr-only today). Unread counts are real (tracked). The hardcoded "6 active" dies.
- Preserve all element IDs, `data-view`/`data-route`, `window.LZ.*` contracts,
  HL signing, Nostr derivation. `seedFromNpub` v1/v2 streams are FROZEN.
- CSP unchanged (`script-src 'self' https://esm.sh`; sigil avatars are `data:` URLs,
  already allowed by `img-src 'self' data: https:`). No inline scripts.
- Perf rules: blur only large non-repeated containers; repeated/live rows get flat
  glass (glass.css strategy). Intervals pause on `document.hidden` / inactive route.
- `prefers-reduced-motion` + `prefers-reduced-transparency` respected everywhere.
- Bump asset cache-bust `?v=8` → `?v=9` in app.html (lesson: stale assets).

## A. Glass 27 (base.css + glass.css + preloader.js + new glass-control.js)
- Convert glass fills/blur to switchable custom props:
  `--glass-blur:20px`, `--glass-blur-strong:28px`, `--glass-blur-soft:12px`
  used by base.css utilities + glass.css applications via
  `blur(var(--glass-blur))` etc. Fill tokens stay `--glass-soft/--glass/--glass-strong-bg`.
- Modes on `<html data-glass>`: `frosted` (default = current values) ·
  `clear` (lower fill alphas ~−.12, blur +6px, sheen +legibility shadow on text-bearing
  rows) · `solid` (near-opaque fills #131319-ish, blur 0px).
- Legibility (iOS-27 cue): in clear mode add `--glass-text-shadow:0 1px 2px rgba(0,0,0,.5)`
  consumed by chat bubbles/list rows; frosted/solid: none.
- Control: 3-segment mono pill (CLEAR/FROST/SOLID) rendered by `assets/js/glass-control.js`
  into the sidebar above `.side-foot`. Persists `localStorage["lz:glass"]`.
  `preloader.js` applies the saved mode pre-paint (external file, CSP-ok, loads first).
  API: `window.LZ.glass = { set(mode), get() }`. `prefers-reduced-transparency`
  still hard-forces solid via existing media queries (CSS wins).

## B. Empty-state kit "Sigil void" (ui.js emptyState v2 + ui.css)
Additive options (existing `{icon,title,body,variant:'error'}` callers untouched):
- `hero:true` — larger type, more padding (route-level states).
- `ring:true` — the dashed sigil-await ring (same language as Identity) behind the
  icon; slow rotation, static under reduced-motion.
- `ghost:'chat'|'rows'` — N blurred skeleton rows behind a frosted veil (clearly
  skeletons, not fake people): the "see the promise through the glass" trick.
- `cta:{label, href}` or `{label, onClick}` — ONE action, `.btn accent sm`.
Markup contract: `.lz-empty[.lz-empty--hero]` > `.lz-empty-stage` (ghost+veil+ring) +
icon/title/body/action. All styles in ui.css.
